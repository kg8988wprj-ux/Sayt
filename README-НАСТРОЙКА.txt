САЙТ УЧЕБНОГО ЦЕНТРА — ВЕРСИЯ ДЛЯ CLOUDFLARE PAGES

В этой версии сохранён дизайн сайта и добавлен Cloudflare Pages Worker для безопасной отправки заявок в Telegram.
Файл _worker.js должен лежать рядом с index.html в корне проекта. Не переносите его в assets.

ВАЖНО: если хотите в будущем редактировать файлы через GitHub и автоматически публиковать изменения, создавайте Pages-проект через Connect to Git. Не выбирайте Direct Upload: такой проект нельзя переключить на Git integration.

ПУБЛИКАЦИЯ ЧЕРЕЗ GITHUB
1. Создайте новый репозиторий GitHub (лучше Private).
2. Загрузите в корень репозитория ВСЕ файлы и папку assets из этого архива. Не загружайте сам ZIP как единственный файл — его нужно распаковать.
3. В Cloudflare откройте Workers & Pages → Create application → Pages → Connect to Git.
4. Подключите GitHub и выберите созданный репозиторий.
5. Для простого HTML-сайта укажите Build command: exit 0; Build output directory: . (корень репозитория). Если Cloudflare автоматически определит настройки из wrangler.toml, проверьте, что выходная папка — корень проекта.
6. Запустите первый deploy.
7. В проекте Cloudflare откройте Settings → Variables and Secrets. Добавьте два ЗАШИФРОВАННЫХ секрета:
   BOT_TOKEN = токен бота от @BotFather
   TELEGRAM_CHAT_ID = ваш числовой Telegram ID или ID группы
8. После добавления секретов запустите новый deploy (Retry deployment / новый commit), чтобы проверить работу с секретами.
9. В Telegram откройте своего бота, нажмите Start и отправьте /start. Для группы добавьте бота в группу и используйте chat ID группы.
10. Проверьте адрес сайта: /api/health должен вернуть telegramConfigured: true.

ПОДКЛЮЧЕНИЕ TELEGRAM
- Создайте бота через @BotFather командой /newbot.
- Никому не отправляйте BOT_TOKEN и не вставляйте его в HTML или JavaScript сайта.
- TELEGRAM_CHAT_ID узнайте через @userinfobot (для личных сообщений) либо получите ID группы, если заявки должны идти в группу.
- Секреты добавляются только в Cloudflare → Settings → Variables and Secrets, тип Secret / Encrypt.

КАК РЕДАКТИРОВАТЬ САЙТ
- index.html — тексты, заголовки, подписи и ссылки.
- styles.css — цвета, размеры, отступы и внешний вид.
- assets/ — фотографии и изображения.
- script.js — поведение формы в браузере.
- _worker.js — серверная отправка заявок; не меняйте без необходимости.
После изменения файлов в GitHub Cloudflare автоматически соберёт новую версию сайта.
